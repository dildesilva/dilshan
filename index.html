Research & Abstract

Current Research Focus

Title: “AI-Driven Threat Detection in Cloud-Native Environments”

This research explores the integration of machine learning models with cloud-native security frameworks to detect and respond to emerging cyber threats in real time. The study focuses on leveraging AWS native services (Amazon GuardDuty, AWS Security Hub, and SageMaker) to build a scalable, intelligent threat detection system that reduces false positives and improves incident response times.

Key Areas: Cloud Security, AI/ML, Anomaly Detection, Zero-Trust Architecture, and Automated Remediation.

Status: Ongoing research in collaboration with academic advisors at Anglia Ruskin University. Expected to contribute to the final-year dissertation and propose a practical framework for SMEs transitioning to cloud-native security.

#CloudSecurity #AI #MachineLearning #AWS #ThreatDetection #ZeroTrust #CyberResilience

Abstract

“Scalable Anomaly Detection in Multi-Cloud Infrastructures Using Ensemble Learning” — This abstract presents a novel ensemble learning approach for detecting anomalous behaviour across distributed cloud environments. By combining unsupervised and supervised techniques, the proposed model achieves 94.2% accuracy with a 3.1% false-positive rate, outperforming traditional signature-based methods. The research addresses the growing need for adaptive security in hybrid cloud deployments and lays the groundwork for future AI-native security operations centres (SOCs).
